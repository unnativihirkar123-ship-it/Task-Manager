# Task Manager

A simple web-based Task Manager developed as a DBMS project. It helps users create, view, update, and delete tasks in an organized way.

## Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Set task priority
- Set task status
- Add task descriptions
- Set due dates
- Database connectivity using MySQL
- REST API using Node.js and Express

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- MySQL Workbench

## How to Run
1. Clone the repository
git clone https://github.com/unnativihirkar123-ship-it/Task-Manager.git
2. Open the project
cd Task-Manager
3. Install backend dependencies
cd backend
npm install
4. Start the server
node server.js

The backend server will start on the configured local port.

5. Open the frontend

Open the frontend index.html file in your browser.

Database

The project uses MySQL to store and manage task-related data.

The backend communicates with the MySQL database through Node.js.
